# Triage labels

Use these label strings whenever a skill refers to a canonical triage role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue. |
| needs-info | needs-info | Waiting for information from the reporter. |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent. |
| ready-for-human | ready-for-human | Requires human implementation or judgment. |
| wontfix | wontfix | Will not be actioned. |

Keep the existing `bug` and `enhancement` category labels. Preserve unrelated labels; create only configured labels that are missing.
