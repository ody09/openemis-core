# ديمو صور الحصص — 3 نوفمبر 2026

الرابط المحلي: http://127.0.0.1:8001/lesson-photo-demo.html

نسخة عرض مستقلة بطلب المستخدم لتوضيح الفكرة خلال المقابلة؛ ليست ميزة تشغيلية مرتبطة بحسابات OpenEMIS أو جدول الحصص.

1. اختر التاريخ والحصة من واجهة المعلم.
2. أضف صورة البداية ثم النهاية، أو استخدم زر «تجربة سريعة بصور توضيحية» لتجهيز المثال المرسوم فورًا.
3. افتح «مراجعة المؤسسة» واعرض الصورتين ووقت الرفع والملاحظة.
4. اعتمد تجريبيًا أو أعد مع سبب؛ تظهر ملاحظة المؤسسة عند المعلم.

الحفظ في IndexedDB داخل المتصفح الحالي فقط. التاريخ والساعة من الجهاز؛ لا يثبتان وقت التصوير أو تنفيذ التدريس. تبويبا المعلم والمؤسسة محاكاة للأدوار دون مصادقة. الشعبة والمعلم ثابتان لتجربة العرض. لا يوجد ربط بالبصمة أو حفظ على السيرفر أو مزامنة بين الأجهزة. ملفات الصور JPG/PNG/WEBP بحد 5 ميجابايت؛ تُفحص قابليتها للقراءة قبل الحفظ. لا تستخدم بيانات أو صور طلاب حقيقية في هذا النموذج.

تحقق: 3 اختبارات Node لحدود الملفات وتسلسل الصور ومراجعة التوثيق. تحقق مرئي بالمثال المرسوم: إنشاء الصورتين، منع الإعادة دون سبب، الاعتماد، وبقاء الصور والقرار بعد تحديث الصفحة. تعذر إكمال منتقي الملفات عبر أداة المتصفح المدمج؛ لم يُتحقق من اختيار ملف فعلي من المتصفح.

قبل التشغيل الفعلي: ربط الحصص والمعلمين وصلاحيات المؤسسة، حفظ خاص على الخادم، وقت خادم وسجل تدقيق، معالجة الإعادة وتصحيح التوثيق، سياسة صور الطلاب، والتكامل مع البصمة.
